`Catalogo.jsx` consulta el catálogo aprobado y perfiles vigentes del backend; permite a escolares y apoderados enviar solicitudes de colegios faltantes.
`GestionarCatalogo.jsx` permite a coordinación agregar cursos y colegios mediante formularios, revisar cursos por grado y consultar solicitudes. La comunicación con el backend usa su formato de API internamente.
